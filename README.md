# Simba Supermarket Retail & Inventory Management System

## Project Overview
The Simba Supermarket System is a web-based Retail and Inventory Management System developed as my university final-year project. It was designed to support supermarket operations, including product management, inventory tracking, sales processing, and reporting.

## Technologies Used
- PHP
- MySQL
- HTML
- CSS
- JavaScript
- XAMPP
- phpMyAdmin

## Key Features
- **User Roles:** Admin, Manager, and Cashier.
- **Inventory Management:** Manage products and monitor stock levels.
- **Point of Sale (POS):** Process sales and generate receipts.
- **Stock Requests:** Support stock requests, approval, and receiving.
- **Reports and Dashboard:** View sales and inventory information.
- **User Management:** Manage system users.

## Development Environment
The system was developed using PHP and MySQL, with XAMPP as the local development environment.

This project demonstrates my practical skills in web development, database management, and building business information systems.
